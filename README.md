# 🌐 Sitio Web del Programa Puente – Geografía

Este repositorio contiene un sitio web básico en HTML para acompañar a estudiantes del Programa Puente en Geografía.

## 📁 Estructura
- `index.html`: Página principal.
- `index.css`: Estilos del sitio.
- `index.js`: Funcionalidad básica.
- `README.md`: Información general del proyecto.

## 🚀 Ver en vivo con GitHub Pages
1. Subí estos archivos a tu repositorio.
2. Activá GitHub Pages en `Settings > Pages`, eligiendo la rama y carpeta raíz.
3. Accedé a tu sitio en: `https://<usuario>.github.io/<repositorio>`
